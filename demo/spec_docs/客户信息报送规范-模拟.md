# 模拟监管报送规范 · 客户信息报表（RPT_CUST_INFO）

> ⚠️ 本文档为 DGA 项目自编演示文档，用于 RAG 演示，不对应任何真实监管制度。

## 第一章 报送范围与频率

1.1 本报表报送全行有效个人及对公客户的基本信息。
1.2 报送频率：每日。数据截止时点为前一自然日 24:00。
1.3 客户状态为"销户"（码值 3）的客户，自销户之日起不再报送。

## 第二章 字段要求

| 序号 | 报送字段 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| 1 | cust_no | CHAR(20) | 是 | 客户号，全行唯一 |
| 2 | cust_name | VARCHAR(128) | 是 | 客户名称 |
| 3 | cert_type | CHAR(1) | 是 | 证件类型，码值见第三章 |
| 4 | cert_no | CHAR(18) | 是 | 证件号码 |
| 5 | phone | CHAR(11) | 是 | 手机号，11 位数字 |
| 6 | email | VARCHAR(64) | 是 | 电子邮箱（2026 年新增必填） |
| 7 | addr | VARCHAR(128) | 否 | 联系地址 |
| 8 | open_date | DATE | 是 | 开户日期 |
| 9 | status | CHAR(1) | 是 | 客户状态，码值见第三章 |

## 第三章 码值与勾稽

3.1 证件类型码值：1=居民身份证；2=护照；3=统一社会信用代码；4=港澳台通行证；9 及其他取值均为**无效码值**，报送前必须整改。

3.2 客户状态码值：1=正常；2=冻结；3=销户。

3.3 勾稽关系：本报表报送的客户数应与《账户信息报表》中 distinct 客户数一致，允许差额不超过 0.5%；超出时应在报送说明中注明原因。

3.4 手机号格式：11 位数字且以 1 开头，第二位限 3-9。
