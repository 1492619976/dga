# 模拟监管报送规范 · 交易信息报表（RPT_TRX_INFO）

> ⚠️ 本文档为 DGA 项目自编演示文档，用于 RAG 演示，不对应任何真实监管制度。

## 第一章 报送范围与频率

1.1 本报表报送当日报送的存款类交易流水，含成功与失败交易（失败交易 status=2 需单独标注）。
1.2 报送频率：每日。

## 第二章 字段要求

| 序号 | 报送字段 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| 1 | trx_id | VARCHAR(20) | 是 | 交易流水号，唯一 |
| 2 | acct_no | CHAR(20) | 是 | 账号 |
| 3 | cust_no | CHAR(20) | 是 | 客户号 |
| 4 | trx_date | DATE | 是 | 交易日期 |
| 5 | amt | DECIMAL(18,2) | 是 | 交易金额，>0 |
| 6 | dr_cr | CHAR(1) | 是 | 1=借；2=贷 |
| 7 | channel | CHAR(2) | 是 | 01柜台 02网银 03手机 04ATM |
| 8 | status | CHAR(1) | 是 | 1=成功；2=失败 |

## 第三章 勾稽关系

3.1 单笔交易金额超过 50 万元的交易列入大额交易，须在报送说明中统计笔数与金额合计。

3.2 同一账号当日借贷总额轧差应与账户余额变动一致。

3.3 交易表中出现的每个 acct_no 必须存在于《账户信息报表》，否则为**孤儿交易**，报送前必须整改。
