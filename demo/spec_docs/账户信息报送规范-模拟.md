# 模拟监管报送规范 · 账户信息报表（RPT_ACCT_INFO）

> ⚠️ 本文档为 DGA 项目自编演示文档，用于 RAG 演示，不对应任何真实监管制度。

## 第一章 报送范围与频率

1.1 本报表报送全行状态正常与止付的存款类账户信息；销户账户不报送。
1.2 报送频率：每日。

## 第二章 字段要求

| 序号 | 报送字段 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| 1 | acct_no | CHAR(20) | 是 | 账号，全行唯一 |
| 2 | cust_no | CHAR(20) | 是 | 所属客户号 |
| 3 | balance | DECIMAL(18,2) | 是 | 账户余额，两位小数 |
| 4 | currency | CHAR(3) | 是 | 币种，默认 156 |
| 5 | status | CHAR(1) | 是 | 1=正常；2=止付 |

## 第三章 勾稽关系

3.1 本报表余额合计应与总账系统存款科目余额核对，差额超过 0.1% 时须出具说明。

3.2 报表中每个 cust_no 必须能在《客户信息报表》中找到；找不到的记录属于**孤儿账户**，应在报送前清理。

3.3 余额为负数的账户属于异常，逐户说明原因后方可报送。
